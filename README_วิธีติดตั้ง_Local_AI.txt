Visual SQL Studio - Local AI BAT installers (Windows)
==========================================================

วิธีใช้งาน
1. เลือกไฟล์ BAT เพียง 1 ตัวตามสเปกเครื่อง
2. ดับเบิลคลิกไฟล์ BAT แล้วกด Y หากต้องการให้ดาวน์โหลดและติดตั้ง Ollama
3. หากยังไม่มี Ollama โปรแกรมจะดาวน์โหลดตัวติดตั้งจาก https://ollama.com
   และตรวจสอบลายเซ็นดิจิทัลของผู้ผลิตก่อนเปิดตัวติดตั้ง
4. ทำตามขั้นตอนติดตั้ง Ollama ที่ปรากฏบนหน้าจอ
5. BAT จะดาวน์โหลดโมเดล AI ที่เลือกและตรวจว่าติดตั้งได้หรือไม่
6. เปิด Visual SQL Studio -> กดค้นหาโมเดลในเครื่อง -> เลือกโมเดล -> ถาม AI ภาษาไทย

เลือกไฟล์ตามสเปก (เป็นคำแนะนำ ไม่ใช่การรับประกันว่าจะเร็วทุกเครื่อง)
- Install_AI_Lite_8GB.bat
  โมเดล qwen2.5-coder:1.5b; ดาวน์โหลดประมาณ 986 MB; เหมาะกับ RAM 8 GB
- Install_AI_Balanced_16GB.bat
  โมเดล qwen2.5-coder:3b; ดาวน์โหลดประมาณ 1.9 GB; แนะนำ RAM 16 GB
- Install_AI_Performance_32GB.bat
  โมเดล qwen2.5-coder:7b; ดาวน์โหลดประมาณ 4.7 GB; แนะนำ RAM 32 GB ขึ้นไป

สิ่งที่ต้องมี
- Windows 10/11 ที่ Ollama รองรับ
- อินเทอร์เน็ตขณะดาวน์โหลด Ollama และโมเดล
- พื้นที่ว่างสำหรับ Ollama และโมเดล (Ollama อาจต้องใช้พื้นที่หลาย GB)
- สิทธิ์ติดตั้งโปรแกรมตามนโยบาย IT ของบริษัท

ความปลอดภัย
- สคริปต์นี้ไม่เชื่อมต่อหรืออ่านข้อมูล Database
- โมเดลเป็นแบบ Local ไม่ใช่โมเดล Cloud; ตั้งค่า OLLAMA_NO_CLOUD=1 และ OLLAMA_HOST=127.0.0.1:11434 ใน User Environment
- หาก Ollama เปิดอยู่ก่อนแล้ว ต้อง Quit ที่ System Tray แล้วเปิดใหม่ เพื่อให้การตั้งค่ามีผล
- ถ้าการตรวจสอบลายเซ็นของ OllamaSetup.exe ไม่ผ่าน จะหยุดการติดตั้งและไม่ข้ามการตรวจสอบ
- ถ้าพบ Ollama เปิดรับการเชื่อมต่อจากเครือข่าย จะหยุดการดาวน์โหลดโมเดลจนกว่าจะแก้การตั้งค่า
- การติดตั้ง Ollama ใช้อินเทอร์เน็ตเพื่อดาวน์โหลดไฟล์ทางการและโมเดล แต่ไม่ได้ส่งข้อมูลบริษัทหรือ SQL ไปให้บริการภายนอก
- โปรดอนุมัติกับฝ่าย IT ก่อนติดตั้งบนโน้ตบุ๊กบริษัท

หากพบข้อผิดพลาด
- Download failed: ตรวจอินเทอร์เน็ต, Proxy, Firewall หรือปรึกษา IT
- Signature verification failed: อย่าข้ามการตรวจ; ติดต่อ IT
- Ollama not detected after setup: ปิด CMD, รีสตาร์ต Windows แล้วเปิด BAT อีกครั้ง
- Ollama did not respond: เปิด Ollama จาก Start Menu หรือเช็กพอร์ต 11434
- Model download failed: ตรวจพื้นที่ว่างและอินเทอร์เน็ต แล้วดับเบิลคลิก BAT ซ้ำได้
- Visual SQL Studio หาโมเดลไม่พบ: เปิด Ollama แล้วกดค้นหาโมเดลในเครื่องใหม่

ตรวจด้วย CMD หากต้องการ:
  ollama list
  ollama --version

หมายเหตุ: ถ้ามี Ollama อยู่แล้ว BAT จะข้ามการติดตั้งโปรแกรม และดาวน์โหลดเฉพาะโมเดลที่เลือก
           ถ้ามีโมเดลอยู่แล้ว Ollama จะใช้ไฟล์เดิม ไม่ดาวน์โหลดทั้งหมดใหม่
           ไม่จำเป็นต้องติดตั้งทั้ง 3 โมเดลพร้อมกัน
